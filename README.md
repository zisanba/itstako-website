# itstako.com

Marketing site for Tako (Turkish and English).

- `_source/pages/`: the page designs (edit these)
- `_source/build.py`: turns the designs into the real pages; run `python3 _source/build.py`
- Everything else in the root (`index.html`, `ozellikler/`, `en/` ...) is built output and is what gets published.

Settings (domain, contact email, form address) are at the top of `_source/build.py`.
